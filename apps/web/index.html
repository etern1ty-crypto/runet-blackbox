Что означает результат

Один адрес, одна сеть, один момент времени. Не полная проверка приложения или загрузки пакетов.

Количество отчётов не подтверждает независимость источников. Это не доказательство блокировки и не SLA.

VPN-помеченные отчёты исключены из сводки по умолчанию. Пустое окно не заменяется демо.
