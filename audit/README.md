# Audit evidence

Фактические результаты локальной проверки ревизии 0.4.0. `baseline-*` относятся к исходному архиву 0.3.1. Остальные test logs относятся к исправленной версии; runtime metadata находится в verification.json.

Screenshots — изображения браузерной QA, а не реальные показания внешних сервисов. Demo помечено явно. В error-state fixture намеренно повреждён JSON и отсутствуют fallback files. Dark screenshot использует ту же dark CSS branch, принудительно включённую в изолированной QA-копии, без изменения исходного stylesheet.

Полный source ZIP содержит эти свидетельства. Lean npm package не обязан включать крупные logs/screenshots.
